# Arquitectura de Constancia

Constancia es un SaaS B2B para emitir constancias profesionales de trabajos y servicios.

## Núcleo funcional

- Registro e inicio de sesión
- Organización multiempresa
- Clientes
- Constancias numeradas
- Fotos y firma
- QR / URL pública verificable
- Próximo service y recordatorios
- Planes y suscripciones
- Integración Mercado Pago
- Preparación para facturación ARCA

## Stack del repositorio

- Next.js 15
- React 19
- TypeScript
- PostgreSQL
- Prisma
- Mercado Pago
- Cloudflare R2 / S3 compatible
- Resend
- Vercel

La aplicación pública actualmente está siendo validada en https://constancia.floot.app mientras se completa el backend productivo y la sincronización del repositorio.
